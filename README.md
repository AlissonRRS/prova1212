# 📦 Estoque Inteligente

> "Nunca mais esqueça o que precisa comprar." 🚀

## Sobre o Projeto

O **Estoque Inteligente** é um projeto desenvolvido com o objetivo de facilitar a organização das compras do dia a dia.

A proposta surgiu a partir de um problema comum enfrentado por muitas pessoas: esquecer itens importantes ao ir ao mercado, perder o foco durante as compras ou ter dificuldades na escolha de determinados produtos.

Além disso, o sistema busca ajudar o usuário a encontrar mercados próximos de forma rápida e prática, tornando toda a experiência de compra mais organizada e eficiente.

## 🎯 Objetivo

O principal objetivo do projeto é auxiliar os usuários a planejarem suas compras de maneira inteligente, evitando esquecimentos e desperdícios.

Com o Estoque Inteligente, o usuário poderá:

- Organizar listas de compras.
- Visualizar itens que precisam ser adquiridos.
- Manter o foco no que realmente necessita comprar.
- Receber orientações para uma melhor experiência de compra.
- Encontrar mercados próximos de sua localização.

## 💡 Problema que o Projeto Resolve

Muitas vezes as pessoas chegam ao mercado e:

- Esquecem produtos importantes.
- Compram itens desnecessários.
- Gastam mais tempo do que o necessário.
- Não sabem qual produto escolher.
- Não conhecem os mercados mais próximos de sua localização.

O Estoque Inteligente foi criado para minimizar esses problemas e proporcionar uma experiência de compra mais eficiente e organizada.

## 🚀 Funcionalidades

- ✅ Organização dos produtos por categorias.
- ✅ Interface simples e intuitiva.
- ✅ Guia "Como Escolher" com dicas de frutas, carnes e peixes.
- ✅ Consulta de mercados, com link para o mapa.
- ✅ Tabela de promoções por dia da semana.
- 🔜 Criação de lista de compras (hoje a tela existe, falta salvar os itens).
- 🔜 Design responsivo para diferentes dispositivos.
